gmx::GridSet Class Reference

#include <gromacs/nbnxm/gridset.h>

Description

Holds a set of search grids for the local + non-local DD zones.

The are three different possible setups:

  • a single grid, this is the standard case without domain decomposition
  • one grid for each domain decomposition zone
  • with test particle insertion there are two grids, one for the system to insert in and one for the molecule that is inserted
