Description

The parameters for the test.

The test will run for combinations of:

  1. Number of atoms
  2. Timestep
  3. Number of steps
  4. Velocity components
  5. Force components
  6. Number of temperature coupling groups
  7. Temperatures
  8. Tau-t (inverse friction constant) for all temp. coupling groups
  9. Random seed
