imdsocket.h File Reference
Library API | Interactive molecular dynamics (IMD)

Description

Implements the parts of the vmdsock.h interface needed for IMD communication.

Author
Martin Hoefling, Carsten Kutzner ckutz.nosp@m.ne@g.nosp@m.wdg.d.nosp@m.e

For more information, see https://www.ks.uiuc.edu/Research/vmd/imd/ for general IMD information and https://www.ks.uiuc.edu/Research/vmd/imd/code/imdapi.tar.gz for the IMD reference implementation and API.
